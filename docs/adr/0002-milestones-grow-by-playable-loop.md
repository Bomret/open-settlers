# 2. Milestones grow by the playable loop

**Status:** Accepted

After the foundation milestones (analysis access, asset layer, map), the roadmap grows the game one
production chain at a time, starting from the smallest playable loop: a castle, a road with flags,
carriers, and a woodcutter whose log reaches storage. Each milestone ends in a mode a person can run and
check by hand. The transport network is the backbone of the game, so it carries real load from the first
playable milestone, and faults in the interplay of systems, such as carrier congestion or goods
priorities, surface early.

## Considered options

- Grow by system (complete building rules, then transport, then all production chains, then military,
  then the computer opponent): clear boundaries per system, but the game becomes playable late and faults
  in the interplay of systems surface late.
- Headless simulation first, rendering last: nothing to see for a long time, and the asset readers stay
  unverified until the end.
- Two phases (a faithful phase, then an extension phase): missions, music, and the split-screen mode are
  original content that fits neither phase. The roadmap uses milestones with the free-play release as the
  first goal.
