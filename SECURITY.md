# Security policy

## Report a vulnerability

Report a vulnerability privately through GitHub:
<https://github.com/Bomret/open-settlers/security/advisories/new>. Do not open a public issue for it.

Give the affected version or commit, the steps that reproduce the problem, and its effect. The engine
reads the files of a game install, so a crafted or corrupt game file that makes the engine misbehave
beyond a reported read failure is in scope.

## Supported versions

Open Settlers has no releases yet. Fixes go into `main`.
